# Security Policy

## Supported versions

Security fixes are applied to the latest released version of each EconViz package on PyPI.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Instead, report them privately through [GitHub Security Advisories](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) ("Report a vulnerability" under the repository's **Security** tab), or by email to **contact@econ-viz.org**.

You can expect an initial response within 7 days.
